项目背景

为什么需要 Multi-Agent 架构？

传统电商客服系统存在三大痛点：意图识别单一（难以处理跨域复杂请求）、响应延迟高（人工介入环节多）、个性化程度低（千人一面）。

本项目基于 Multi-Agent 架构构建电商智能服务平台，通过专业智能体分工协作，实现从商品发现、订单管理到售后履约的全链路智能化服务。

核心技术深度

扎实的技术功底

LangGraph 智能体引擎

基于 LangGraph 搭建通用 ReAct 智能体框架，统一封装 5 个智能体的构建流程。

  • StateGraph 构建 LLM 推理 ↔ 工具执行条件循环
  • 多 LLM 兼容补丁层（通义千问等工具调用字段补全）
  • 异步工具执行，最大迭代次数防死循环

A2A 智能体间通信

实现跨智能体可靠通信，支持同步与流式双模式。

  • HTTP/1.1 + JSON，message:send / message:stream
  • 双模式认证：Local 共享密钥 / OAuth2 RS256 JWT
  • OTel 分布式追踪 + 流式失败自动降级

pgvector 向量语义检索

基于 PostgreSQL 16 + pgvector 实现商品语义检索。

  • 1536 维 Embedding 向量，IVFFlat 余弦索引
  • 语义搜索 + 相似推荐 + 趋势分析三类模式
  • 库存/价格过滤后排序输出

双模式认证 + HITL 审批

Local/OAuth 双模式一键切换，高风险操作引入人机协作。

  • HS256 JWT / RS256 + JWKS 公钥验证
  • 启动时 Pydantic 强制校验密钥强度
  • 5 类高风险操作走 HITL 审批队列（阈值 $500）
